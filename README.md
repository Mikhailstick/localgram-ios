# LocalGram — личный клиент с локальными подарками

Клиент Telegram для iOS с разделом **Настройки → Мои функции**.
Вход по номеру, коду и паролю двухэтапной проверки, несколько аккаунтов,
чаты и медиа берутся из базового клиента. Новые функции встроены в него.

**Статус: реализация подготовлена в исходниках. IPA ещё не собран.**
Синтаксис проверен на Windows; компиляция, Swift-тесты и запуск на iOS 26 пока не проверены.

## Добавленные функции

- Ввод виртуального баланса Stars, включая нулевой баланс.
- Выбор реального Telegram-пользователя через экран контактов и поиск.
- Каталог обычных подарков и коллекционные варианты маркетплейса.
- Поиск NFT по ссылке t.me/nft/Название-номер.
- Отправка обычного подарка, NFT или Stars только в локальном отображении.
- Точное списание цены в Stars и проверка недостаточного баланса.
- Нативная карточка подарка в переписке, история и остаток баланса.
- Раздельное хранение по аккаунтам, восстановление после перезапуска, скрытие карточки и сброс.
- Собственная иконка и название LocalGram.

Отправка из этого раздела не вызывает покупку, перевод подарка или отправку сообщения через API.
Карточки вставляются в отображаемую историю без записи в очередь исходящих сообщений.
Получателю они не поступают. Нажатие на карточку открывает локальную квитанцию.

## Текущие границы

- Виртуальные Stars показаны в «Моих функциях». Обычный серверный раздел Stars сохраняет свой баланс.
- Карточки отображаются в переписках и локальной истории. Вкладка подарков профиля остаётся серверной.
- Поддержаны предложения маркетплейса с целой ценой в Stars. Лоты только за TON не списывают Stars.
- Поиск по NFT-ссылке требует доступной цены в Stars в загруженной карточке.
- Для каталогов, файлов подарков и контактов нужен вход и доступ к Telegram.
- Sideload-сборка содержит главное приложение. Расширения Share, Siri, Widgets и другие
  исключены из этого варианта из-за ограничений прав личной подписи.
  Сборку с расширениями можно делать по стандартной инструкции базового клиента.
- Фоновые push-уведомления с личной подписью не проверены.

## Сборка без своего Mac

Подготовлен ручной workflow .github/workflows/local-gifts.yml.
Образ macos-26 содержит Xcode 26.2 согласно
[списку runner-images](https://github.com/actions/runner-images/blob/main/images/macos/macos-26-Readme.md),
проверенному при подготовке проекта. Workflow проверяет наличие нужного Xcode.
Сборка ещё не запускалась. Ограничения ресурсов GitHub могут потребовать отдельного Mac-runner.

1. Подготовить GitHub-репозиторий с исходниками. Для экспортированного архива
   выполнить bootstrap.py: он восстановит закреплённую версию и применит изменения.
2. Получить **API ID приложения и API Hash приложения** на https://my.telegram.org/apps.
   Это не код входа, не пароль Telegram и не код двухэтапной проверки.
3. Добавить repository secrets TELEGRAM_API_ID и TELEGRAM_API_HASH.
4. Открыть Actions → Build LocalGram IPA → Run workflow.
5. После успешной компиляции скачать артефакт LocalGram-unsigned-IPA.
6. Извлечь LocalGram-unsigned.ipa, открыть Sideloadly на Windows, подключить iPhone
   и подписать/установить файл своим Apple ID.

Архив исходников нельзя установить на iPhone как приложение: для установки нужен собранный .ipa.

## Сборка на Mac

Требуются macOS, Xcode 26.2, его компоненты и зависимости базового проекта.
Для полного checkout и подмодулей выполнить:

    git sparse-checkout disable
    git submodule update --init --recursive

Задать TELEGRAM_API_ID и TELEGRAM_API_HASH в окружении, затем:

    python3 LocalGifts/build_ipa.py --check
    python3 LocalGifts/build_ipa.py

Скрипт сначала запускает swift test, затем собирает полный Telegram/Telegram target через Bazel.
При успехе экспортирует только реальный файл из bazel-bin/Telegram/Telegram.ipa.
Конфигурация с API Hash временно сохраняется в игнорируемом каталоге и удаляется после сборки.

## Проверки после сборки

1. Войти в тестовый аккаунт, проверить код и двухэтапный пароль.
2. Установить 1000 Stars, отправить подарок ценой P: баланс должен стать 1000 − P.
3. Открыть переписку: локальная карточка видна; на устройстве получателя её нет.
4. Повторить с NFT и со Stars, проверить двойное подтверждение и недостаточный баланс.
5. Перезапустить приложение: баланс и карточки должны сохраниться.
6. Переключить аккаунт: локальные карточки первого аккаунта отсутствуют во втором.
7. Проверить светлую/тёмную тему, длинные имена и большие числа.
8. Скрыть карточку, перезапустить клиент: карточка не возвращается, списанная цена не возмещается.

Экраны и анимации нужно проверить на симуляторе и iPhone; проверка исходников не заменяет запуск.

## Основа и лицензии

Версия закреплена в LocalGifts/upstream.json. Release-тег в репозитории Swiftgram содержит
базовый Telegram iOS; функции текущего Swiftgram master отдельно не перенесены.
Сохраняются инструкции и лицензии базового проекта и его библиотек.
LocalGram — рабочее название личного клиента.
